  1. Chrome နဲ့ ဒီစာမျက်နှာကို ဖွင့်ပါ။
  2. အပေါ်က “ဖုန်းထဲ ထည့်မယ်” ခလုတ် ပေါ်ရင် နှိပ်ပါ။
  3. မပေါ်ရင် ညာဘက်အပေါ် ⋮ → “Add to Home screen” ဒါမှမဟုတ် “Install app” ကို နှိပ်ပါ။
  4. Home Screen မှာ Dokodemo icon ပေါ်လာပါမယ်။

🤖 Android APK ထည့်နည်း

  1. အပေါ်က “Android APK ဒေါင်းလုဒ်” ကို နှိပ်ပါ။ (Chrome က “ဒေါင်းလုဒ် လုပ်မလား” မေးရင် Download)
  2. ဒေါင်းပြီးရင် Open / 開く ကို နှိပ်ပါ။ (သို့) Files app → Downloads ထဲက Dokodemo.apk ကို နှိပ်ပါ။
  3. “ဒီနေရာက app ထည့်ခွင့်မရှိဘူး” ပေါ်ရင် → Settings → Allow from this source ကို ဖွင့်ပြီး နောက်ပြန် (←) နှိပ်ပါ။
  4. Install ကို နှိပ်ပါ။ Play Protect က သတိပေးရင် More details → Install anyway ကို နှိပ်ပါ။
  5. Home Screen မှာ Dokodemo icon ပေါ်လာပါမယ် 🎉
Play Store မှာ မတင်ရသေးလို့ ဖုန်းက သတိပေးတာ ပုံမှန်ပါ။ စကားလုံး၊ မေးခွန်း အသစ်တွေကို App ထဲမှာ အလိုလို ရပါတယ်။ APK က Android ဖုန်း အတွက်ပဲ ဖြစ်ပါတယ် — iPhone ဆိုရင် အပေါ်က “Home Screen ထဲ ထည့်နည်း” ကို သုံးပါ။
