  index.html  download.html  manifest.webmanifest  sw.js

※ MyaingAdmin.html ကို ဘယ်တော့မှ မတင်ပါနဲ့။

[အဆင့် ၀] Zip ဖြည်ပါ
  Android: Files app → zip ကို နှိပ် → Extract
  iPhone : ဖိုင် (Files) app → zip ကို နှိပ်ရင် folder ဖြစ်သွားမယ်

[အဆင့် ၁] github.com ကို Chrome / Safari နဲ့ ဖွင့် → Sign up
  Username ဥပမာ: myaingstudy

[အဆင့် ၂] ညာဘက်အပေါ် "+" → New repository
  Repository name: myaingstudy.github.io  (username + .github.io)
  Public → Create repository

[အဆင့် ၃] "uploading an existing file" နှိပ် → choose your files
  ဖိုင် ၉ ခုလုံး ရွေး → အောက်ဆုံး "Commit changes"
  (ခလုတ် မတွေ့ရင် browser menu → "Desktop site / デスクトップ用サイト" ဖွင့်ပါ)

[အဆင့် ၄] Settings → Pages → Branch: main → / (root) → Save
  ၁–၂ မိနစ်နေရင်
    App        : https://myaingstudy.github.io/
    ဒေါင်းလုဒ်   : https://myaingstudy.github.io/download.html  ← ဒါကို မျှဝေပါ

[ဗားရှင်းအသစ် တင်နည်း]
  1) index.html အသစ်ကို Add file → Upload files နဲ့ တင် (ဟောင်းကို အစားထိုးမယ်)
  2) sw.js ထဲက 'myaing-v1' ကို v2, v3 … ပြောင်းပြီး တင်
     (GitHub ပေါ်မှာ sw.js ကို နှိပ် → ✏️ နဲ့ တိုက်ရိုက် ပြင်လို့လည်း ရ)
